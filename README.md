# Model Context Protocol (MCP) 信息网站

这是一个复古风格的网页，展示有关Model Context Protocol (MCP)的信息。网页设计采用了2000年初期的经典风格，包含了闪烁文本、访问计数器、老式导航等元素。

## 页面特点

- 2000年代风格的网页设计
- 表格布局
- 渐变背景
- 访问计数器
- 闪烁文本效果
- "最佳浏览器"提示
- 经典的按钮设计

## 内容概述

本网页包含以下有关MCP的信息：

1. MCP的基本介绍
2. MCP的优势和用途
3. MCP的架构
4. MCP的应用
5. 流行的MCP服务器
6. 采用MCP的公司
7. MCP相关资源链接

## 如何使用

1. 直接在浏览器中打开`mcp-info.html`文件即可查看网站内容
2. 通过左侧导航栏可快速跳转到不同的信息部分

## 技术说明

- 使用纯HTML和CSS构建
- 不依赖任何JavaScript框架
- 兼容所有现代浏览器
- 使用内联Base64图像数据

## 许可

本项目仅用于学习和展示目的。MCP相关内容参考了公开资料。
